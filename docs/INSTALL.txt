SqlWorkbench development build for SSMS 22 (x64). Untested prototype; no affiliation with Redgate.

Install
1. Save your work and close SSMS 22.
2. Right-click the zip > Properties > Unblock (if shown), then extract it.
3. In the extracted folder open PowerShell and run:
     powershell -ExecutionPolicy Bypass -File .\Install-SqlWorkbench.ps1
   (Double-clicking SqlWorkbench.Ssms.vsix may also work, but the script targets the SSMS 22 instance explicitly.)
4. Start SSMS 22 and open a new query window.

Try
- Type ssf then press Tab            -> SELECT * FROM
- F12 on a @variable / alias / CTE   -> jumps to its declaration
- Tools > Options > SqlWorkbench > Offline schema SQL file = offline-schema.sql from this folder,
  then type "SELECT * FROM " to see the suggestion popup, or put the caret after * and press Tab.
- Tools menu: SqlWorkbench commands (format, analyze, semicolons, rename, ...)

Uninstall
  powershell -ExecutionPolicy Bypass -File .\Install-SqlWorkbench.ps1 -Uninstall
