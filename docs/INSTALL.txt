Querywright development build for SSMS 22 (x64). Untested prototype; no affiliation with Redgate.

Install
1. Save your work and close SSMS 22.
2. Right-click the zip > Properties > Unblock (if shown), then extract it.
3. Double-click Install.cmd in the extracted folder.
   (Same as: powershell -ExecutionPolicy Bypass -File .\Install-Querywright.ps1
    Double-clicking Querywright.Ssms.vsix may open Visual Studio's installer instead of SSMS's.)
4. Start SSMS 22 and open a new query window.

Try
- Type ssf then press Tab            -> SELECT * FROM
- F12 on a @variable / alias / CTE   -> jumps to its declaration
- Tools > Options > Querywright > Offline schema SQL file = offline-schema.sql from this folder,
  then type "SELECT * FROM " to see the suggestion popup, or put the caret after * and press Tab.
- Tools menu: Querywright commands (format, analyze, semicolons, rename, ...)

Update
  Querywright shows a notice in SSMS when a newer release is published (once a day; turn off under
  Tools > Options > Querywright > Updates). Download the new zip and repeat the Install steps:
  the newer version replaces the installed one and keeps your settings, snippets and tab history.

Uninstall
  Close SSMS 22, then from a command prompt in this folder:  Install.cmd -Uninstall
